# Uploaded UI Source Reference

This directory contains the original React/Vite UI design supplied for the James AI Journal Club project.

The deployable Streamlit app is located at the repository root:

```text
app.py
```

The React source is preserved here for design provenance, future front-end development, and portfolio review. Its palette and component language have been ported into the Streamlit CSS in `app.py`; it is not installed or built during Streamlit Community Cloud deployment.
